# 🛡️ SafeGuard AntiFish Defense v1.0.0

**SafeGuard AntiFish Defense** - Android-приложение для дополнительной защиты от фишинга, интернет-мошенничества, подозрительных ссылок, QR-кодов, потенциально опасных приложений и сетевых угроз.

Проект разрабатывается с акцентом на локальный анализ,конфиденциальность пользователя и понятное объяснение обнаруженных рисков.

## 🔐 Основные возможности

🔗 Анализ подозрительных ссылок и доменов  
🎣 Обнаружение признаков фишинга и поддельных сайтов  
📞 Определение и проверка номеров при звонках  
📷 Проверка QR-кодов перед переходом  
📦 Анализ APK-файлов и приложений  
🌐 Local VPN и дополнительная сетевая защита  
🚫 Сетевой карантин приложений в поддерживаемых сценариях  
🗃️ Локальная IOC-база индикаторов угроз  
🧬 YARA-анализ доступных для проверки объектов  
🧠 Эвристический анализ и оценка риска  
💬 Анализ подозрительных текстов и признаков социальной инженерии  
🔔 Уведомления о событиях безопасности  
📊 История проверок и обнаруженных событий

## 🛡️ Privacy Shield

В проект также развивается модуль **SafeGuard Privacy Shield** для повышения контроля пользователя над сетевой активностью приложений.

Его задачи:

- обнаружение известных рекламных и tracking-доменов;
- блокировка выбранных категорий через SafeGuard Local VPN;
- обнаружение advertising, analytics, attribution и telemetry endpoints;
- отображение приложений с privacy-related сетевой активностью;
- подробная история сетевых обращений;
- Allowlist / Blocklist;
- индивидуальные правила для приложений;
- реальные счётчики заблокированных запросов;
- локальная база правил с возможностью безопасного обновления;
- работа локальных механизмов без постоянного подключения к облаку.

SafeGuard разделяет **Privacy Risk** и **Security Risk**.

Наличие аналитики или рекламного SDK само по себе не означает, что приложение является вредоносным или «шпионит» за пользователем. SafeGuard должен показывать наблюдаемые факты и объяснять причину каждого предупреждения или блокировки.

## 🔒 Privacy by Design

SafeGuard создаётся с принципом минимизации обрабатываемых данных.

Для выполнения обычных локальных проверок приложению не требуется содержимое:

- паролей;
- PIN-кодов;
- CVV;
- OTP/SMS-кодов;
- личной переписки.

Если содержимое зашифрованного соединения технически недоступно, SafeGuard не должен делать вид, что знает, какие именно данные были переданы.
